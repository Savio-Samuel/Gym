Acesse o projeto online:

## 📖 Sobre o projeto

A **Gym Landing Page** é uma página desenvolvida para apresentar uma academia de forma moderna e organizada.

Durante o desenvolvimento deste projeto, coloquei em prática diversos conceitos aprendidos recentemente em HTML e CSS, buscando criar um layout limpo, bem estruturado e agradável visualmente.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto, pratiquei:

- Estrutura semântica do HTML
- Flexbox
- Backgrounds
- Pseudo-classes (`:hover`)
- Controle de exibição com `overflow: hidden`
- Box Model
- Margin
- Padding
- Variáveis CSS (`:root`)
- Boas práticas na estruturação do código
